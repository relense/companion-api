# Companion Outreach API

A backend service to handle cold outreach messaging, built with Express, Supabase, and OpenAPI.

## Features

- CRUD operations for messages
- Pagination with metadata and links
- OpenAPI + Swagger documentation
- Input/output validation via express-openapi-validator
- Secure API key authentication

## Tech Stack

- Node.js / Express
- Supabase (PostgreSQL)
- OpenAPI + Swagger UI
- TypeScript
- [Optional] Vitest / Supertest for tests
